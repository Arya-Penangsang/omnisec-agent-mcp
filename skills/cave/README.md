## ⚡ How to Install

### 1. Claude Web (claude.ai) & Claude Desktop
1. Generate the ZIP package using the OmniSec bridge:
   ```bash
   python bridge/skills_bridge.py pack --skill cave
   ```
2. In claude.ai / Claude Desktop, go to **Settings > Capabilities > Skills**.
3. Upload `dist_packages/cave.zip` and enable the toggle.

### 2. Claude Code CLI
```bash
python bridge/skills_bridge.py sync --target claude-code
```
*(Or copy the `skills/cave/` directory to `~/.claude/skills/cave`)*

### 3. Google Antigravity
```bash
python bridge/skills_bridge.py sync --target antigravity
```
*(Or copy to `~/.gemini/config/skills/cave`)*

### 4. Cursor / Windsurf IDE
Included automatically via `.cursorrules` or `.windsurfrules` generated by the bridge CLI:
```bash
python bridge/skills_bridge.py sync --target cursor
```
